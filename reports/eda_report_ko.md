# GMSC 탐색적 데이터 분석 보고서 (2단계)

> 교육용으로만 사용합니다. 실제 금융 의사결정에 사용하지 마십시오.

- 입력: `data/processed/gmsc_clean.csv` (149,999행, 1단계 결과물)
- 코드: `notebooks/eda.py` (프로젝트 루트에서 `python notebooks/eda.py` 실행)
- 그림: `reports/figures/*_ko.png`, `*_en.png`. 수치: `reports/eda_summary.json`

## 1. 주요 발견

1. **클래스 불균형이 큽니다.** 대출자의 6.68%가 부도입니다 (149,999명 중 10,026명). 5단계에서 클래스 가중치와 SMOTE를 비교하는 이유입니다. (그림 01)
2. **연체 이력이 가장 강한 신호입니다.** 60~89일 또는 90일 이상 연체가 1회 이상이면 부도율이 약 5%에서 30% 이상으로 오르고, 3회 이상이면 약 60%가 됩니다. (그림 02)
3. **리볼빙 사용률은 조치 가능한 변수 중 가장 강합니다.** 사용률이 낮은 구간의 약 1.4%에서 상위 10% 구간(0.98 초과)의 23.4%까지 부도율이 오릅니다. (그림 02)
4. **씬파일러는 약 2배 위험합니다.** 기준 규칙에 해당하는 비율은 7.71% (11,564행)이며, 부도율은 12.93%로 그 외 집단의 6.16%보다 높습니다. (그림 07)
5. **96/98 코드 집단은 매우 위험합니다.** 부도율이 54.6%로, 심각한 연체가 2회 이상인 집단과 비슷합니다. (그림 05)

## 2. `actionability.yaml`과의 방향 일치 점검

각 변수를 구간(10분위, 횟수형 변수는 횟수)으로 나눠 부도율을 계산했습니다. "역전"은 이웃한 구간 사이에서 전체 추세와 반대로 움직인 횟수입니다.

| 변수 | YAML `monotone` | 관찰된 추세 | 역전 | YAML과 일치 |
|---|---|---|---|---|
| 리볼빙 사용률 | +1 | 증가 | 1 (최하위 구간만) | 예 |
| 30~59 / 60~89 / 90일 이상 연체 | +1 | 증가 | 0 | 예 |
| 부채비율 | +1 | 증가, 단 U자형 | 3 | 예, 약함 |
| 월 소득 | -1 | 감소 | 1 (최하위 구간만) | 예 |
| 연령 | 0 (보호 속성) | 감소 | 0 | 제약 없음 |
| 보유 대출·신용한도 수 | 0 | U자형 | 4 | 제약 없음 |
| 부동산 담보대출 수 | 0 | U자형 | 3 | 제약 없음 |
| 부양가족 수 | 0 | 증가 | 0 | 제약 없음 |

제약을 거는 변수는 모두 YAML과 같은 방향으로 움직입니다. **부채비율이 약한 경우입니다.** 중간 구간에서 부도율이 내려갔다가 약 0.43 이상에서만 뚜렷하게 오르며, 부도와의 Pearson r은 거의 0입니다. 5단계에서 단조 제약으로 인한 AUC 손실이 생긴다면 가장 유력한 원인이며, 손실이 0.01을 넘으면 가장 먼저 제외할 제약입니다.

## 3. 부도와의 상관 (그림 06)

| 변수 | Pearson r | Spearman |
|---|---|---|
| 90일 이상 연체 | +0.315 | +0.335 |
| 리볼빙 사용률 | +0.282 | +0.241 |
| 30~59일 연체 | +0.275 | +0.251 |
| 60~89일 연체 | +0.268 | +0.268 |
| 연령 | -0.115 | -0.117 |
| 나머지 | 0.05 미만 | 0.07 미만 |

**3단계에 중요한 점:** 실제 변수 중 관측 |r| 0.3에 도달하는 것은 하나뿐입니다. 같은 방식으로 측정하면 0.3~0.5 규칙은 각 시뮬레이션 변수를 가장 좋은 실제 신용 변수만큼 강하게 만듭니다. 최종 결정 (미션 준수): 체크리스트가 `df.corr()`로 확인하므로 미션 변수 5개를 관측 Pearson r −0.32로 보정합니다. 따라서 각각이 어떤 실제 신용 변수보다 강하며 (단독 AUC 0.80~0.84), 대체 데이터를 쓴 결과가 낙관적인 이유입니다 (`simulator_report_ko.md` 참고).

Pearson r은 극단값에 왜곡됩니다. 예를 들어 부채비율은 Pearson -0.002, Spearman +0.058입니다. 따라서 3단계에서는 모든 시뮬레이션 변수에 대해 잠재, Pearson, Spearman 상관을 함께 보고합니다.

## 4. 변수 간 관계 (그림 04)

- 순위 상관 0.4 이상인 쌍: 부채비율과 부동산 담보대출 수 (0.61), 보유 대출·신용한도 수와 부동산 담보대출 수 (0.47), 부채비율과 보유 대출·신용한도 수 (0.41).
- 연체 횟수 3개 열은 서로 중간 정도만 관련되어 있어 (0.24~0.30), 각각 별도의 정보를 줍니다.
- 연령은 리볼빙 사용률 (-0.28), 부양가족 수 (-0.23)와 음의 관계입니다. 연령은 보호 속성이므로 공정성 분석에 중요합니다. 다른 변수가 연령을 일부 대신할 수 있습니다.

## 5. 분포 (그림 03)

- 리볼빙 사용률은 봉우리가 두 개입니다. 0 근처(대부분 정상)와 1.0 근처(부도자가 몰림).
- 부채비율은 0에서 튀고 오른쪽으로 꼬리가 깁니다. 부도자가 약간 높은 쪽에 있습니다.
- 부도자의 소득은 다소 낮은 쪽으로 치우쳐 있지만 두 집단이 많이 겹칩니다.

## 6. 이후 단계에 미치는 영향

- **3단계:** 상관계수 정의 결정됨: 미션 변수는 관측 Pearson r −0.32 (3절 참고).
- **5단계:** 부채비율 제약의 AUC 비용을 먼저 확인합니다. 로지스틱 회귀는 치우침 때문에 부채비율, 소득, 사용률에 로그 변환이나 상한 처리가 필요합니다.
- **공정성 (채민규):** 연령이 사용률, 부양가족 수와 관련되어 있으므로, 연령만 제거해서는 연령 효과가 사라지지 않습니다.
