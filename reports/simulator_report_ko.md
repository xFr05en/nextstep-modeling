# 대체 데이터 시뮬레이터 보고서 (3단계)

> 교육용으로만 사용합니다. 실제 금융 의사결정에 사용하지 마십시오. 모든 대체 변수와 성별은 관측값이 아닌 시뮬레이션 값입니다.

- 코드: `src/data/simulator.py` (실행: `python -m src.data.simulator`), 설정: `config/simulator.yaml`
- 상충 관계 분석과 그림: `notebooks/simulator_report.py` (실행: `python notebooks/simulator_report.py`)
- 결과물: `data/processed/gmsc_sim.csv` (주 데이터셋, b = 0.30), `data/processed/gmsc_sim_target_only.csv` (비교용, b = 0)
- 수치: `reports/simulator_summary.json`, `reports/simulator_sweep.json`. 그림 08~10: `reports/figures/` (한국어, 영어)

**헌장 규칙의 해석:** 상관 0.3~0.5 규칙은 코퓰라의 잠재 상관(변수의 숨은 점수와 숨은 부도 점수 간 상관)에 적용하며, 0/1 부도 열과의 관측 Pearson 값을 함께 제시합니다.

## 1. 시뮬레이터 작동 방식

각 대체 변수는 표준정규 척도의 숨은 점수 `z`에서 출발합니다.

`z = -(a × T + b × w × C) + noise × e`

| 구성 요소 | 의미 |
|---|---|
| `T` | 숨은 부도 점수. 부도자는 정규분포 상위 6.68%에서, 정상 대출자는 나머지에서 값을 뽑습니다. |
| `C` | 실제 GMSC 데이터로 만든 신용 행동 점수. 연체 횟수 합계와 리볼빙 사용률을 각각 순위 기반 정규 점수로 바꿔 더합니다. 높을수록 나쁨. |
| `e` | 변수마다 독립적인 무작위 잡음. |
| `a` | 잠재 상관 r(z, T)가 모든 변수에서 -0.35가 되도록 보정합니다. `z`에 신용 부분이 포함되므로 전체를 보정합니다. |
| `b × w` | 신용 행동과의 연결 강도. 주 데이터셋 b = 0.30. 가중치 w는 정시납부율 두 개에 1.0, 가입 기간·보험 납부 개월·자동이체에 0.5. |

마이너스 부호 때문에 값이 높을수록 부도 위험이 낮아지며, 이는 `actionability.yaml`의 요구와 같습니다. 코퓰라 단계에서 `z`의 순위를 각 변수의 실제 분포(베타, 감마, 이항, 6단계 이산)로 변환합니다. 시드 42를 사용하므로 같은 시드는 같은 데이터를 만듭니다.

**신용 부분의 결측 처리:**
- 특수코드(96/98) 269행은 1단계 이후 연체 횟수가 없습니다. 부도율이 54.65%이므로 연체 행동이 가장 나쁜 순위로 둡니다.
- 사용률 이상치(10 초과) 241행의 부도율은 7.05%로 평균 6.68%와 비슷합니다. 더 위험하다는 근거가 없으므로 중립 점수(척도의 가운데인 0)를 줍니다.

**가입 기간 상한:** 통신사 가입 기간은 (연령 - 18) × 12개월을 넘을 수 없습니다. 상한이 적용된 행은 0.69%입니다.

**성별:** 별도의 50:50 무작위 추출. 여성 비율 50.26%, 부도와의 상관 0.0007.

## 2. 변수별 결과 (주 데이터셋, b = 0.30)

| 변수 | 잠재 r | 관측 Pearson r | Spearman r | 단독 AUC |
|---|---|---|---|---|
| 통신요금 정시납부율 | -0.350 | -0.273 | -0.235 | 0.763 |
| 공과금 정시납부율 | -0.350 | -0.273 | -0.234 | 0.762 |
| 통신사 가입 기간 | -0.350 | -0.176 | -0.209 | 0.742 |
| 건강보험·연금 납부 개월 | -0.350 | -0.223 | -0.207 | 0.737 |
| 자동이체 비율 | -0.350 | -0.202 | -0.202 | 0.731 |

신용 연결이 없는 비교용 버전 (부도에만 의존, b = 0):

| 변수 | 잠재 r | 관측 Pearson r | Spearman r | 단독 AUC |
|---|---|---|---|---|
| 통신요금 정시납부율 | -0.350 | -0.188 | -0.172 | 0.693 |
| 공과금 정시납부율 | -0.350 | -0.185 | -0.171 | 0.691 |
| 통신사 가입 기간 | -0.350 | -0.153 | -0.176 | 0.704 |
| 건강보험·연금 납부 개월 | -0.350 | -0.184 | -0.174 | 0.700 |
| 자동이체 비율 | -0.350 | -0.171 | -0.171 | 0.695 |

**예상값 확인:** 부도율 6.68%에서 잠재 상관 0.35는 관측 Pearson r 약 0.18, AUC 약 0.70을 줄 것으로 예상했습니다. 비교용 버전에서 확인되었습니다 (Pearson 0.15~0.19, AUC 0.69~0.70).

**같은 잠재 r인데 연결 버전이 더 강한 이유:** 숨은 부도 점수 `T`에는 각 집단 안에서 실제 결과와 무관한 무작위 변동이 들어 있습니다. 신용 점수 `C`는 실제 데이터에서 오므로, 실제 0/1 결과와의 관계가 `T`와의 관계보다 강합니다. 따라서 `C`를 일부 포함한 변수는 잠재 r이 0.35로 같아도 실제 부도에 대한 정보가 더 많습니다 (Pearson 최대 0.27, AUC 최대 0.76).

**실제 신용 변수와의 관계 (주 데이터셋):** 정시납부율 두 개는 연체 횟수 합계와 -0.25, 사용률과 -0.27의 상관을 보입니다. 연결을 절반만 쓰는 나머지 세 변수는 둘 모두와 -0.13~-0.16입니다.

**대체 변수 간 상관:** Pearson r 0.12~0.19로 상한 0.60보다 훨씬 낮습니다. 정시납부율 두 개의 상관은 0.19여서 잡음을 늘릴 필요가 없었습니다 (모든 변수의 잡음 1.0 유지).

가입 기간 상한의 영향은 거의 없습니다. 가입 기간이 다른 변수보다 연령과 더 관련되지 않습니다. 작은 양의 관계는 간접적으로 생깁니다. 나이가 많은 대출자는 사용률이 낮고 부도가 적은데, 시뮬레이터가 변수를 이 둘과 연결하기 때문입니다. 비교용 버전에서는 0.02~0.03입니다. 즉 대체 변수는 연령을 약하게만 대신하며, 신용 행동 연결이 이를 2~4배로 키웁니다.

## 5. 상충 관계: 신용 행동 연결과 AUC 향상 (그림 08)

LightGBM 기본 설정, 부도 여부와 씬파일러 플래그로 층화한 5겹 교차검증, 두 모델에 같은 폴드를 사용했습니다. 향상 폭은 대체 데이터 포함 AUC에서 미포함 AUC를 뺀 값입니다. GMSC만 사용한 AUC는 전체 0.865, 씬파일러 0.850입니다.

| 신용 연결 b | 씬파일러 향상 | 전체 향상 | 대체 데이터 포함 씬파일러 AUC | 변수별 단독 AUC 평균 |
|---|---|---|---|---|
| 0 (부도에만 의존) | +0.075 ± 0.010 | +0.068 | 0.925 | 0.697 |
| 0.15 | +0.071 ± 0.009 | +0.064 | 0.922 | 0.723 |
| **0.30 (주 데이터셋)** | **+0.067 ± 0.008** | **+0.061** | **0.918** | **0.747** |
| 0.45 | +0.065 ± 0.007 | +0.060 | 0.915 | 0.768 |

(±는 5개 폴드의 표준편차 1배입니다.)

**설명 방법:** 변수를 신용 행동과 연결하면 씬파일러 향상 폭이 +0.075에서 +0.067로 0.007 (약 10%) 줄어듭니다. 각 변수의 단독 성능은 오히려 좋아지는데도 (평균 AUC 0.70에서 0.75) 그렇습니다. 이유는 중복입니다. 변수가 아는 정보의 일부가 이미 연체 횟수와 사용률에 들어 있어 새로 더해지는 정보가 적어집니다. 모든 설정에서 향상 폭은 목표 +0.03보다 높습니다. 이웃한 설정 간 차이는 폴드 간 변동보다 작으므로, 개별 단계가 아니라 전체적인 감소 추세만 제시해야 합니다.

## 6. 한계

- **시뮬레이션 편향 (주요 한계).** 대체 변수는 실제 부도 열로부터 생성되므로, 테스트 폴드에 들어가는 행을 포함해 모든 행의 값이 이미 결과를 "알고" 있습니다. 시뮬레이션에서는 피할 수 없지만, 절대적인 향상 폭 (+0.067)은 낙관적이며 실제 통신·공과금 데이터가 줄 성능으로 읽으면 안 됩니다. 상충 관계의 패턴 (방향과 상대적 크기)이 더 신뢰할 만한 결과입니다.
- **향상 폭은 우리가 정한 설정에 달려 있습니다.** 잠재 상관 목표 (0.35), 연결 강도 b, 가중치는 실제 대체 데이터에서 추정한 값이 아니라 팀이 정한 값입니다.
- **전체 AUC가 높습니다 (대체 데이터 포함 0.926).** 서로 독립적인 부도 정보원 다섯 개에서 나온 결과이므로 최선의 경우로 보아야 합니다.
