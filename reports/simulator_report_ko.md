# 대체 데이터 시뮬레이터 보고서

> 교육용으로만 사용합니다. 실제 금융 의사결정에 사용하지 마십시오. 모든 대체 변수와 성별은 관측값이 아닌 시뮬레이션 값입니다.

- 코드: `src/data/simulator.py` (실행: `python -m src.data.simulator`, 미션 형식 진입점 `generate_alternative_data()`), 설정: `config/simulator.yaml`
- 시나리오 점검: `notebooks/simulator_scenarios.py` → `reports/simulator_scenarios.json`. 신용 연결 분석과 그림 08~10: `notebooks/simulator_report.py`
- 결과물: `data/processed/gmsc_sim.csv` (주 데이터셋, b = 0.30), `data/processed/gmsc_sim_target_only.csv` (비교용, b = 0)

**중요:** 시뮬레이터는 나중에 테스트 세트에 들어가는 행을 포함해 **모든** 행에 실제 부도 열을 사용합니다. 미션의 예시 시뮬레이터도 같은 방식입니다. 따라서 대체 데이터를 쓰는 모든 결과는 낙관적이며, **현실적인 기준은 GMSC만 사용한 모델**입니다 (테스트 AUC 약 0.86).

## 1. 변수 8개

| 변수 | 역할 | 범위 | 분포 | 상관 규칙 |
|---|---|---|---|---|
| `telecom_payment_rate` | 미션 | 0~1 (1/12 단위) | Beta(8, 1.5) | 관측 Pearson r = −0.32 |
| `utility_payment_rate` | 미션 | 0~1 (1/12 단위) | Beta(8, 1.5) | 관측 Pearson r = −0.32 |
| `spending_consistency` | 미션 | 0~100 | Beta(5, 2) × 100 | 관측 Pearson r = −0.32 |
| `regular_payment_count` | 미션 | 0~20, 정수 | Binomial(20, 0.75) | 관측 Pearson r = −0.32 |
| `app_login_frequency` | 미션 | 0~30, 정수 (로그인한 날 수) | Binomial(30, 0.75) | 관측 Pearson r = −0.32 |
| `telecom_tenure_months` | 추가 | 0~240, (연령 − 18) × 12 상한 | Gamma(2, 24) | 잠재 r = −0.35 |
| `insurance_paid_months` | 추가 | 0~24 | Binomial(24, 0.75) | 잠재 r = −0.35 |
| `autopay_ratio` | 추가, **모델 변수 아님** | 0~1 (0.2 단위) | 6단계 이산 | 잠재 r = −0.35 |

납부율 두 개는 `telecom_ontime_rate` / `utility_ontime_rate`에서 미션 이름으로 바꿨습니다 (같은 변수). 부호는 음수이며, 값이 높을수록 부도 위험이 낮습니다.

## 2. 값 생성 방식

각 변수는 표준정규 척도의 숨은 점수에서 출발합니다.

`z = -(a × T + b × w × C) + g × F + e`

| 구성 요소 | 의미 |
|---|---|
| `T` | 숨은 부도 점수 (부도자는 정규분포 상위 6.68%에서 추출) |
| `C` | 연체 횟수와 리볼빙 사용률만으로 만든 신용 행동 점수 (연령, 성별 없음) |
| `F` | 미션 변수 5개만 공유하는 무작위 공통 요인 |
| `e` | 변수별 독립 잡음 |
| `a` | 변수별 보정: 미션 변수는 0/1 타깃과의 **관측** Pearson r = −0.32 ± 0.005 (체크리스트가 확인하는 `df.corr()` 값), 추가 변수는 **잠재** r(z, T) = −0.35 |
| `b × w` | 실제 신용 행동과의 연결: b = 0.30, 납부율 두 개는 w = 1.0, 나머지는 0.5 |
| `g` | 미션 변수 두 개 사이의 최대 상관이 0.60 이하가 되도록 탐색 (달성 0.591) |

코퓰라 단계에서 `z`의 순위를 각 변수의 분포로 변환합니다. 시드 42로 고정하며, 같은 시드는 같은 데이터를 바이트 단위로 재현합니다.

**공통 요인을 쓰는 이유:** 미션 변수 5개가 정보를 공유하도록 하여 함께 더해지는 효과를 제한합니다. 효과는 크지 않습니다. 전체 모델 CV AUC는 평균 쌍 상관 0.30에서 0.968, 0.45에서 0.959, 최대 쌍 0.60 (선택)에서 0.957입니다.

**횟수 변수에 이항분포를 쓰는 이유:** 포아송 분포에서는 부도자가 낮은 값에 몰려, 관측 r = −0.32에 도달하려면 훨씬 강한 숨은 연결이 필요했습니다 (단독 AUC 0.86). p = 0.75 이항분포는 납부율처럼 왼쪽 꼬리가 길어 단독 AUC가 0.83입니다. 포아송 평균을 높여도 (λ 10 / 18) 개선되지 않았습니다 (0.86 / 0.85).

## 3. 변수별 결과 (주 데이터셋)

| 변수 | 관측 Pearson r | 잠재 r | Spearman r | 단독 AUC | 신용 점수와의 r | 연령과의 r |
|---|---|---|---|---|---|---|
| telecom_payment_rate | −0.323 | −0.471 | −0.273 | 0.806 | −0.287 | +0.079 |
| utility_payment_rate | −0.320 | −0.465 | −0.270 | 0.802 | −0.288 | +0.078 |
| spending_consistency | −0.318 | −0.525 | −0.277 | 0.821 | −0.202 | +0.056 |
| regular_payment_count | −0.316 | −0.555 | −0.287 | 0.828 | −0.202 | +0.057 |
| app_login_frequency | −0.323 | −0.559 | −0.293 | 0.835 | −0.199 | +0.056 |
| telecom_tenure_months | −0.176 | −0.350 | −0.209 | 0.742 | −0.176 | +0.065 |
| insurance_paid_months | −0.223 | −0.350 | −0.207 | 0.737 | −0.202 | +0.056 |
| autopay_ratio | −0.203 | −0.350 | −0.203 | 0.731 | −0.189 | +0.052 |

- **미션 규칙 충족:** 관측 |r|이 전체 데이터에서 0.316~0.323, train / validation / test 각 분할에서 0.314~0.339입니다 (테스트로 확인).
- **8개 변수 중 두 변수 간 최대 상관:** 0.591 (상한 0.60).
- **성별:** 50:50, 부도와의 상관 0.0007.

**강도 경고:** 미션 변수는 각각 단독으로 AUC 0.80~0.84에 도달하여 어떤 실제 GMSC 변수보다 강합니다. 부도율 6.7%에서의 관측 r 규칙 때문이며, 전체 모델이 테스트 AUC 0.95에 도달하는 주된 이유입니다.

## 4. `app_login_frequency`와 연령

미션 예시는 앱 로그인을 연령과 연결하지만, **이 시뮬레이터는 연결하지 않습니다.** 연령이 보호 속성이기 때문입니다. 신용 부분은 연체 횟수와 사용률만 사용하며, `age`를 섞어도 신용 점수가 바뀌지 않음을 테스트로 확인했습니다. 그래도 연령과 +0.056의 상관이 있는데, 간접적인 관계입니다. 나이가 많은 대출자는 사용률이 낮고 부도가 적기 때문입니다. 미션 연령대별 평균: **22.3일 (20~34세), 22.4일 (35~54세), 22.6일 (55세 이상)**.

## 5. 시나리오 파라미터

| 파라미터 | 기본값 | 효과 |
|---|---|---|
| `thin_filer_ratio` | None (자연 비율 7.71%) | `subsample` 방식: 큰 집단을 비복원 추출해 비율을 맞춤 (0.15 → 77,093행, 0.30 → 38,547행). `mask` 방식 (시연 전용): 연체 컬럼을 비워 미션 규칙이 해당 비율을 판정하게 함 (0.30 → 정확히 30.0%) |
| `bias_ratio` | 0.0 | 여성과 20~34세 집단의 숨은 점수를 `bias_ratio` 표준편차만큼 낮춤, 범위 [0, 1] |

미션 예시의 기본값은 0.3 / 0.1입니다. 우리 기본값이 None / 0.0인 이유는 최종 모델을 자연 구성과 편향 없는 데이터로 학습해야 하기 때문입니다.

**편향 시나리오 (최종 설정을 5겹 교차검증으로 재학습, 미션 연령대):**

| bias_ratio | 성별 승인율 격차 / DI / EO 격차 | 연령대 승인율 격차 / DI / EO 격차 |
|---|---|---|
| 0.0 | 0.001 / 0.999 / 0.011 | 0.152 / 0.836 / 0.127 |
| 0.2 | 0.033 / 0.963 / 0.062 | 0.157 / 0.831 / 0.132 |
| 0.5 | 0.074 / 0.918 / 0.132 | 0.156 / 0.832 / 0.151 |

- **성별:** 측정 편향 효과가 뚜렷합니다. 여성과 남성의 부도율은 6.7%로 같지만 여성의 승인율은 86.6%에서 82.8%로 떨어집니다.
- **연령대 (발견):** 재학습이 이동을 대부분 상쇄합니다. 연령이 모델 변수이므로 모델이 젊은 신청자의 대체 데이터가 낮게 나온다는 것을 학습해, 승인율 격차와 DI가 거의 변하지 않습니다. EO 격차는 여전히 커집니다.
- 미션 변수의 잠재 연결 `a`는 0.5에서만 바뀝니다. r이 ±0.005 안에 들어오면 보정을 멈추기 때문입니다.

## 6. 신용 연결과 AUC 향상 (그림 08)

LightGBM 기본 설정, 5겹 교차검증, 미션 변수는 항상 관측 r −0.32.

| 신용 연결 b | 씬파일러 향상 | 전체 향상 |
|---|---|---|
| 0 (부도에만 의존) | +0.101 ± 0.015 | +0.090 |
| 0.15 | +0.095 ± 0.014 | +0.084 |
| **0.30 (주 데이터셋)** | **+0.088 ± 0.014** | **+0.078** |
| 0.45 | +0.083 ± 0.014 | +0.073 |

변수를 실제 신용 행동과 연결하면 b = 0.30에서 향상 폭이 약 13% 줄어듭니다. 정보의 일부가 연체 횟수, 사용률과 겹치기 때문입니다. 모든 설정에서 향상 폭은 +0.03보다 훨씬 높습니다.
