# German Credit 보조 모델 (실제 성별 공정성 점검용)

> 교육용으로만 사용합니다. 실제 금융 의사결정에 사용하지 마십시오. 별도의 작은 모델이며, GMSC 파이프라인, 설정, 최종 모델은 바뀌지 않았습니다.

**데이터 출처:** Hofmann, H. (1994). Statlog (German Credit Data) [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C5NC77. CC BY 4.0 라이선스.

- 코드: `src/german.py` (실행: `python -m src.german`, 약 20초), 설정과 라벨 매핑: `config/german.yaml`
- 데이터: UCI에서 `german.data`를 `data/raw/`로 내려받음 (git 제외, 커밋하지 않음)
- 결과물: `reports/german/oof_predictions.csv` (채민규용), `reports/german/metrics.json`
- 테스트: `tests/test_german.py`

## 1. 데이터

- 신청자 1,000명, 속성 20개, 결측 없음. 부도율 30%.
- 모든 범주 코드 (A11, A43, ...)를 UCI 문서에 따라 읽을 수 있는 라벨로 변환했습니다.
- 타깃 변환: **1 = 부도** (원래 2 = 불량), 0 = 정상.
- **성별**은 속성 9 (혼인 상태와 성별)에서 만듭니다: A92 = 여성, A91/A93/A94 = 남성. A95 (미혼 여성)는 데이터에 없습니다.

| 집단 | 행 수 | 부도율 |
|---|---|---|
| 여성 (모두 "이혼/별거/기혼") | 310 | 35.2% |
| 남성 | 690 | 27.7% |
| 30세 미만 | 371 | 36.9% |
| 30~49세 | 504 | 25.6% |
| 50세 이상 | 125 | 27.2% |
| 외국인 노동자: 예 | 963 | 30.7% |
| 외국인 노동자: 아니오 | 37 | 10.8% |

기술 통계일 뿐이며, 공정성 지표는 채민규 담당입니다.

## 2. 변수

- **변수에서 제외하고 평가용으로만 유지:** 속성 9 (혼인 상태와 성별), 속성 20 (외국인 노동자).
- **변수 18개:** 숫자형 7개 (대출 기간, 대출 금액, 할부 비율, 현 거주 기간, **연령**, 기존 대출 수, 부양 인원)와 범주형 11개 (학습 폴드 안에서 원-핫 인코딩).
- **연령은 단조 제약 없는 변수로 사용합니다.** GMSC 모델과 같은 방식입니다.

**단조 제약:** 방향이 분명하고 구간별 데이터가 이를 확인하는 숫자형 변수에만 적용합니다 (5분위별 부도율):

| 변수 | 구간별 부도율 | 제약 |
|---|---|---|
| 대출 기간 (개월) | 21%, 18%, 32%, 33%, 48% | +1 |
| 할부 비율 (소득 대비 %) | 25%, 27%, 29%, 33% | +1 |
| 대출 금액 | 30%, 24%, 27%, 26%, 43% (U자형) | 없음 |
| 연령 | 39%, 32%, 26%, 26%, 25% | 없음 (GMSC와 동일) |
| 거주 기간, 기존 대출 수, 부양 인원 | 뚜렷한 패턴 없음 | 없음 |

대출 금액까지 제약하면 AUC가 0.008 낮아집니다. 사용한 제약 2개의 비용은 0.0009입니다.

## 3. 결과

로지스틱 회귀 기준 모델과 XGBoost (300트리, 깊이 3, 학습률 0.05). 반복 층화 5겹 교차검증 10회 (모델당 50회 학습). "± 표준편차"는 10회 반복 간 값이며, 범위는 50개 폴드 전체입니다.

| 모델 | AUC | AUC 범위 (50폴드) | KS | KS 범위 | Brier |
|---|---|---|---|---|---|
| 로지스틱 회귀 | 0.780 ± 0.007 | 0.697~0.844 | 0.469 ± 0.015 | 0.317~0.600 | 0.169 |
| **XGBoost (제약)** | **0.789 ± 0.008** | 0.723~0.859 | **0.485 ± 0.017** | 0.379~0.619 | 0.164 |
| XGBoost (제약 없음, 참고) | 0.790 ± 0.010 | 0.717~0.866 | 0.481 ± 0.018 | 0.391~0.638 | 0.164 |

- XGBoost가 LR보다 AUC 평균 0.009 높고 (폴드 간 표준편차 0.018), 폴드의 68%에서 더 좋습니다. 폴드 간 변동에 비하면 작은 차이입니다.
- 제약 비용은 AUC 0.0009 (표준편차 0.005)입니다. 전체 데이터에서 제약 모델은 대출 기간과 할부 비율에서 반대 방향 이동이 0회, 제약 없는 모델은 각각 344회와 49회였습니다.
- 각 검증 폴드가 200행뿐이라 폴드별 AUC가 0.72~0.86으로 넓게 퍼집니다. 개별 폴드가 아니라 평균을 사용하십시오.

## 4. 채민규용 파일: `reports/german/oof_predictions.csv`

| 열 | 의미 |
|---|---|
| `row_id` | `german.data`의 행 번호 (0~999) |
| `pd_xgb`, `pd_lr` | out-of-fold 부도 확률, 10회 반복 평균. 모든 값은 해당 행을 학습하지 않은 모델에서 나옴 |
| `default` | 실제 결과 (1 = 부도) |
| `sex` | female / male (속성 9에서 생성, 모델 변수 아님) |
| `age` | 연령 (모델 변수) |
| `personal_status` | 속성 9 전체 라벨 (성별과 혼인 상태) |
| `foreign_worker` | yes / no (모델 변수 아님) |

- 평균 PD는 잘 보정되어 있습니다: 평균 29.5% (XGBoost), 30.0% (LR), 실제 30%. AUC는 0.795 (XGBoost), 0.783 (LR)로, 평균하면 잡음이 줄어 단일 실행보다 약간 높습니다.
- **승인 기준과 결정 열은 없습니다.** 기준점은 채민규가 정합니다.

**UCI 비용 행렬 (기준점 선택에 중요):** UCI는 불량 대출자를 승인하는 것이 우량 대출자를 거절하는 것보다 **5배 나쁘다**고 명시합니다 (비용 5 대 1). PD가 보정되어 있다면 승인 비용은 5 × PD, 거절 비용은 1 × (1 − PD)이므로 손익분기점은 0.5가 아니라 **PD = 1/6 ≈ 0.167**입니다. 따라서 비용을 반영한 기준점은 0.5 기준보다 훨씬 많이 거절하며, 이는 집단별 승인율과 공정성 결과를 바꿉니다. 참고용 정보이며 기준점은 적용하지 않았습니다.

## 5. 한계

- **1,000행뿐:** 폴드별 결과가 크게 다르고 (AUC 0.72~0.86), 작은 집단은 매우 작습니다 (50세 이상 125명, 비외국인 노동자 37명, 이혼·별거 남성 50명).
- **미혼 여성이 없음:** "여성"은 이혼·별거·기혼 여성뿐이고 "남성"에는 미혼 남성이 포함됩니다. 따라서 성별이 혼인 상태와 일부 섞여 있으며, 성별 격차의 일부는 혼인 상태 격차일 수 있습니다.
- **대리 변수:** 성별과 외국인 노동자 여부는 변수가 아니지만, 다른 변수 (예: 주거 형태, 직업, 연령)가 같은 정보를 일부 담을 수 있습니다.
- **오래된 지역 데이터:** 1994년 독일, 금액 단위는 마르크(DM). 현재의 대출 상황을 설명하지 않습니다.
- **GMSC와 별개:** 변수와 타깃 정의가 다르므로 GMSC 모델과 수치를 비교할 수 없습니다.
