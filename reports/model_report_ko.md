# 모델 보고서

> 교육용으로만 사용합니다. 실제 금융 의사결정에 사용하지 마십시오. 대체 변수는 테스트 세트를 포함한 모든 행의 실제 결과로부터 시뮬레이션되었으므로 (미션 예시와 같은 방식), 대체 데이터를 쓴 결과는 낙관적입니다. 현실적인 기준은 GMSC만 사용한 모델입니다.

- 코드: `src/train.py` (실행: `python -m src.train --stage all`, 약 7분), 설정: `config/train.yaml`, 점수 체계: `config/scoring.yaml`
- 그림과 SHAP: `python notebooks/model_report.py` (그림 11, 12, `reports/shap_global_top10.csv`)
- 결과: `reports/final_summary.json` (공식), `reports/model_comparison.csv`, `reports/monotonic_results.csv`, `reports/grade_table.csv`, `reports/cv_fold_auc.csv`
- 모델: `models/xgboost_v1.0.joblib`. MLflow 안내: `reports/mlflow_schema_ko.md`

## 1. 실험 설정

| 분할 | 행 수 | 용도 |
|---|---|---|
| Train (70%) | 104,999 | 모델 비교: 27개 실행, 3회 반복 층화 5겹 교차검증 (타깃 × 씬파일러), 선정 규칙 |
| Validation (15%) | 22,500 | 결정: 단조 제약 AUC 손실 (향후 기준점·공정성 조정도 여기서) |
| Test (15%) | 22,500 | train + validation으로 학습한 배포 모델이 한 번만 사용 |

- 분할은 `stratify=y` (모든 분할에서 부도율 6.68%)이며, 팀 전체가 쓰도록 `data/processed/split.csv`로 저장합니다.
- 중앙값 대체, LR 변환, 표준화, SMOTE는 파이프라인 단계로, 학습 폴드에서만 학습합니다.
- 변수 21개: GMSC 14개 (원본 10개 + 정제 플래그 4개), 대체 변수 7개. `autopay_ratio`와 `gender_female`은 데이터에 있지만 모델 입력이 아닙니다.
- 하이퍼파라미터 고정 (실행별 튜닝 없음). 점수 475 승인 기준은 `config/scoring.yaml`의 고정 규칙이며, 어떤 기준점도 테스트 데이터로 정하지 않습니다.

## 2. 모델 비교 (train 교차검증, 15개 폴드, 그림 11)

| 모델 | 불균형 처리 | GMSC만 | 대체 데이터만 | 둘 다 | 씬파일러 향상 | Brier (둘 다) | F1 (둘 다) |
|---|---|---|---|---|---|---|---|
| LR | 없음 | 0.850 | 0.914 | 0.939 | +0.103 | 0.037 | 0.514 |
| LR | 클래스 가중치 | 0.855 | 0.915 | 0.940 | +0.099 | 0.098 | 0.235 |
| LR | SMOTE | 0.855 | 0.914 | 0.939 | +0.100 | 0.096 | 0.245 |
| LightGBM | 없음 | 0.862 | 0.911 | 0.942 | +0.090 | 0.036 | 0.535 |
| LightGBM | 클래스 가중치 | 0.861 | 0.911 | 0.941 | +0.090 | 0.082 | 0.286 |
| LightGBM | SMOTE | 0.854 | 0.910 | 0.942 | +0.107 | 0.036 | 0.508 |
| **XGBoost** | **없음** | **0.864** | **0.913** | **0.942** | **+0.090** | **0.036** | **0.533** |
| XGBoost | 클래스 가중치 | 0.862 | 0.912 | 0.942 | +0.091 | 0.087 | 0.260 |
| XGBoost | SMOTE | 0.851 | 0.911 | 0.941 | +0.109 | 0.037 | 0.468 |

AUC는 15개 폴드의 평균입니다 ("둘 다" 실행의 표준편차는 모두 0.002~0.003).

- **모델 선택보다 대체 데이터 추가가 훨씬 중요합니다:** AUC 약 +0.08, 세 알고리즘의 차이는 최대 0.003.
- **불균형 처리는 AUC를 높이지 않습니다.** 클래스 가중치는 예측 확률을 부풀려 (Brier 0.036 → 0.087), 고정 기준점에서 더 많은 신청자가 기준 아래로 내려가 F1이 낮아집니다.
- **SMOTE의 향상 폭이 큰 것은 더 좋은 모델이라는 뜻이 아닙니다:** SMOTE가 GMSC만 쓰는 기준 모델을 더 많이 낮춥니다.
- **"대체 데이터만"이 "GMSC만"보다 높은 것**은 실제 데이터가 아니라 시뮬레이션 설정 때문입니다.
- **선정 규칙:** "둘 다" 실행 중 CV AUC 최고, 표준편차 1배 이내는 동률로 보고 불균형 처리 "없음"을 우선. **결과: XGBoost, 불균형 처리 없음.**

## 3. 단조 제약 (validation)

YAML `monotone` 필드의 제약 13개: 사용률, 연체 횟수 3개, 부채비율은 +1, 소득과 대체 변수 7개는 −1. 연령, 대출·신용한도 수, 부동산 담보대출 수, 부양가족 수, 플래그 4개는 제약 없음.

| 모델 | Validation AUC 제약 없음 | 제약 | 손실 (95% 짝지은 부트스트랩 CI) |
|---|---|---|---|
| XGBoost | 0.9438 | 0.9438 | **0.0000** (−0.0012~+0.0011) |
| LightGBM | 0.9430 | 0.9436 | −0.0007 (−0.0020~+0.0006) |

제거한 제약이 없습니다 (한도 0.01). 배포 모델은 제약 변수 13개 모두에서 반대 방향 이동이 0회입니다 (테스트로 확인).

## 4. 공식 결과: 테스트 세트 (train + validation으로 학습한 배포 모델)

95% 구간은 테스트 행의 부트스트랩 500회.

| 목표 | 테스트 결과 | 95% CI | 통과 |
|---|---|---|---|
| AUC ≥ 0.78 | **0.949** | 0.944~0.953 | 예 |
| KS ≥ 0.28 | **0.760** | 0.745~0.776 | 예 |
| 씬파일러 AUC 향상 ≥ +0.03 | **+0.071** | +0.052~+0.092 (짝지은 부트스트랩) | 예 |
| PSI (train + validation 대 test) < 0.1 | **0.0004** | | 예 |
| 단조 제약 AUC 손실 ≤ 0.01 | **0.0000** (validation) | −0.0012~+0.0011 | 예 |

- **씬파일러 향상:** 대체 데이터 포함 씬파일러 AUC 0.932, 같은 설정에서 GMSC 변수만 쓴 경우 0.861 (테스트 세트 씬파일러 1,761명, 부도 221명). train 교차검증 추정치는 +0.090이었으며, 테스트 값이 낮은 것은 교차검증의 일반적인 낙관성과 적은 씬파일러 부도 수 때문입니다.
- **점수 475 기준의 정밀도 / 재현율 / F1** (양성 클래스 = 부도, 부도 예측 = 거절): 0.414 / 0.810 / **0.548** (F1 CI 0.529~0.566).
- **보정:** 평균 예측 PD 6.60%, 실제 6.68%, Brier 0.035. 불균형 처리가 없어 보정 단계가 필요 없었습니다.
- **PSI 관련:** train과 test는 같은 모집단의 무작위 표본이므로 PSI가 구조적으로 0에 가깝습니다. 시간에 따른 변화(drift) 검증은 아닙니다 (GMSC에 날짜 없음).

## 6. 점수, 등급, 승인 (테스트 세트, 그림 12)

점수 = 600 + (50 / ln 2) × ln(odds / 50), 0~1000으로 자름. 승인: 등급 A~C (점수 475 이상). 경로 목표: 495 (`recourse_target_score`, 재학습해도 경로가 유지되도록 기준점보다 20점 높게).

| 등급 | 점수 | 비율 (전체) | 비율 (씬파일러) | 평균 예측 PD | 실제 부도율 |
|---|---|---|---|---|---|
| A | 600 이상 | 65.7% | 53.2% | 0.5% | 0.3% |
| B | 530~599 | 13.9% | 12.8% | 3.2% | 2.6% |
| C | 475~529 | 7.3% | 8.7% | 7.2% | 9.3% |
| D | 420~474 | 4.3% | 6.2% | 14.2% | 15.4% |
| E | 420 미만 | 8.8% | 19.1% | 53.3% | 54.0% |

승인율: 전체 86.9%, **씬파일러 74.7%**, 그 외 88.0%. 승인된 대출자의 부도율 1.5%, 거절된 대출자 41.4%.
